# GSPy_turbofan_sim

This repository contains the codes for finishing the GSPy assignment 1 for the course AE4263 (TU Delft).

To reproduce the result of tasks Q1 and Q2, please swtich to the branch `turbofan_OOP_v2`. This branch works with **GSPy v2.0**. The result is comparable with **GSPy v1.6**.
To reproduce the result of tasks Q3 to Q6, please switch to the branch `task_3to6`. This branch and `main` work with **GSPy v1.6**
